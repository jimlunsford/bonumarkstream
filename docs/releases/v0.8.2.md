# Bonumark Stream v0.8.2: Core Interaction and Reliability Pass

**Publicly released September 26, 2026.** Superseded by v0.8.3 on November 4, 2026. The release contains the accepted core work originally merged into the historical develop branch at 8b29f8c627616ac090573c5c5a09943d80f0d6f1. That preparation history is retained; develop has since been retired.

## Federation and administration

Eligible approved local and remote comments share one public Comment total. Eligible local and active current-generation remote Likes share one public Like total without exposing private reaction identities. Moderation, Undo/removal, live updates, and reloads use the same eligibility rules. Stale-generation and ineligible interactions do not count.

Published owner federated replies remain ordinary local posts with permalinks and conversation context, but do not appear in the ordinary main Stream, pinned list, or archives. Following remains private.

ActivityPub Admin prioritizes the profile/handle, Following, Followers, moderation, settings, and diagnostics. Lists have bounded pagination; global failures remain visible and permanent deactivation is separated in the Danger Zone. Signing identity, federation lifecycle, permissions, and CSRF boundaries are preserved.

## Publishing and media

Generated metadata preserves Unicode, including when mbstring is unavailable. Composer failures retain editable input; asynchronous failures retain selected files. A full navigation requires selecting files again. Submission receipts protect retries against duplicate posts and block blind retry after an uncertain outcome.

Alt text is explicitly limited to 255 Unicode code points. Rejected Admin input is retained for correction. Authored descriptions remain authoritative; absent descriptions do not copy post titles/excerpts. Empty alt remains empty, without assuming decorative intent. Gallery controls state the image position and description availability.

Media usage correctly includes current post/Page galleries and legacy import references. Profile and revision-only references are outside the report. Unknown usage is not zero usage, and the report does not certify permanent deletion as safe.

## Accessibility and reliability

Stream card convenience navigation respects selected text, pointer drags, modified clicks, and interactive children. Core landmarks and skip destinations improve orientation on untitled documents without adding fake headlines.

Comments expose stable polite status, busy/error semantics, and conditional focus restoration while preserving drafts during background updates. Like controls visibly name Like or Liked alongside their count. Core asset fingerprints prevent stale CSS/JavaScript during same-version development.

Automated and DOM checks cover these contracts. Development acceptance includes Jim's 390 x 844, 360 x 800, and real phone/touch checks plus controlled live federation. The subsequent exact-release acceptance also passed at 390 x 844 and 360 x 800, as recorded in the public release. Actual screen-reader listening remains unverified.

## Upgrade impact

Adds no database migration. The migration directory remains unchanged through 0028. A healthy public v0.8.1 installation has no new migration to run. Use the existing Admin ZIP or owner-run upgrade workflow with a verified backup. Preserve configuration, installed lock, database content, accounts, posts/Pages, media/uploads, settings, custom themes, ActivityPub state and signing identity, and the migration ledger.
